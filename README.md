# 长夜将尽 · Last Light

一个俯视角的「幸存者」小游戏：在黎明到来前，于无尽的黑夜中活下来。
玩法参考《黎明前20分钟》，但所有美术、音效、特效均由代码实时生成，没有外部素材依赖。

## 怎么玩

**双击 `index.html` 就能玩。** 如果浏览器限制本地文件，也可以在游戏目录里运行：

```bash
python serve.py
```

然后打开 <http://127.0.0.1:5178>。

## 操作

| 按键 | 作用 |
| --- | --- |
| `W A S D` | 移动 |
| `空格` | 冲刺（短暂无敌，可穿过敌人） |
| 自动 | 自动瞄准最近的敌人并射击 |
| 按住鼠标左键 | 临时定向瞄准并射击，松开恢复自动 |
| `1 / 2 / 3` | 升级时选择强化 |
| `Esc` / `P` | 暂停 |
| `M` | 静音 |
| 触屏 | 左下虚拟摇杆移动，右下按钮冲刺 |

## 四种模式

- **标准**：20 分钟完整长夜，难度循序渐进。
- **快速**：8 分钟浓缩夜晚，节奏更快。
- **噩梦**：20 分钟，敌人更硬、更痛，为老练者准备。
- **每日试炼**：8 分钟，每天 00:00 刷新。同一天所有玩家的强化序列完全一致，余烬奖励 +40%，并记录当日最佳。

## 三种武器

进入任意模式后先选择起手武器，选择会被记住：

- **守夜人手枪**：均衡可靠，单发高伤，带 1 点穿透。
- **守夜人霰弹枪**：一次 5 颗弹丸，贴脸爆发极高，血量更厚。
- **连发手弩**：射速极快、弹道精准，适合走位与手感流。

## 内容

- 6 种普通敌人 + 4 场 Boss 战，每场 Boss 有不同的攻击方式；Boss 降临前有 3 秒预警。
- 精英怪带三种词缀：**狂暴**（更快更痛）、**护盾**（先破蓝盾，脱战恢复）、**分裂**（死亡炸出三只小怪）。
- Boss 血量降到一半时进入**狂暴阶段**：移速、攻速、弹幕密度与伤害全面提升。
- 26 种强化、5 档稀有度，每局随机三选一，可重掷；每次升级保证至少一张输出牌。
- **武器进化**：把对应强化点满并在 8 级后升级，会出现金色进化卡——手枪→黎明裁决、霰弹枪→熔火风暴、手弩→千影连弩，各自拥有独立弹道与特效。
- **守夜灯塔**：战场三处据点，圈内累计停留 8 秒点亮；每座给予 20% 最大生命治疗、当前升级需求 65% 的经验和一枚护盾，离开不丢进度。
- **精准闪避**：冲刺擦过敌方弹幕且不与弹幕重叠时，冷却减少 0.6 秒并获得 2 秒射速 +25%；一轮冲刺只触发一次，相对运动检测支持低帧率，结算与本地战绩记录次数。
- **暂停装备笔记**：查看当前强化等级、下一次武器进化条件及据点进度。
- **雨夜氛围**：程序化雨丝、水洼、涟漪与灯塔暖光；低画质限制预算，减少动态时停用雨丝。
- 暴击、穿透、散射、燃烧、冰冻、连锁闪电、爆炸、环绕光球、荆棘光环、吸血、复活等 Build。
- 四种功能掉落：磁石（吸取全部经验）、夜火（清场爆破）、时之沙（冻结敌人）、守夜护盾（抵挡一次伤害）。
- 屏幕震动、命中停顿、慢动作、伤害数字、粒子、血迹、雾气、动态光照、黎明渐变。
- 低血量红晕与心跳反馈；Boss / 精英 / 心形掉落在屏幕外时有边缘箭头指示。
- 右上角战术雷达：竞技场全貌、敌人分布、精英 / Boss 位置、掉落物与扫描线。
- 程序化 WebAudio 音效与环境氛围声；战斗强度提升时会叠加鼓点与军鼓，Boss 战切换低沉不谐和长音。
- 设置面板：主音量、屏幕震动、伤害数字、减少动态效果、战术雷达、高对比度、色盲辅助、大号 HUD、动态战斗音乐、画质（自动 / 高 / 低）。
- 自动画质：帧率持续偏低时自动降档，恢复后自动升回。
- 守夜人档案：总场次、总击杀、通关次数、最佳存活，以及 8 项成就。
- 余烬天赋：每局结算获得余烬，可永久提升伤害、生命、移速与拾取范围。
- 结算详情：命中率、承受伤害、最高连击、冲刺次数与本局构筑回顾。
- 触屏支持：虚拟摇杆 + 冲刺按钮，手机与平板可直接游玩。
- 最高纪录、武器选择、设置、成就、天赋、余烬与最近 20 场战绩均保存在浏览器本地。

## 文件结构

```
index.html      页面、UI、样式（Cinzel 字体已内嵌）
js/art.js       所有怪物 / 地面 / 装饰 / 特效的程序化绘制
js/audio.js     WebAudio 音效与氛围声
js/upgrades.js  强化池与稀有度
js/game.js      游戏主循环、战斗、Boss、渲染、光照
js/nightwatch.js 定向瞄准、灯塔与闪避的纯逻辑
js/atmosphere.js 程序化雨丝、水洼、灯塔绘制
tests/          零依赖 Node 回归测试
serve.py        本地无缓存服务器（可选）
```

## 自动测试

在游戏目录运行（无需安装依赖）：

```bash
node --test tests/*.test.cjs
```
