# 长夜将尽 · Last Light

一个俯视角的「幸存者」小游戏：在黎明到来前，于无尽的黑夜中活下来。
玩法参考《黎明前20分钟》，但所有美术、音效、特效均由代码实时生成，没有外部素材依赖。

## 怎么玩

**双击 `index.html` 就能玩。** 如果浏览器限制本地文件，也可以在游戏目录里运行：

```bash
python serve.py
```

然后打开 <http://127.0.0.1:5178>。

## 操作

| 按键 | 作用 |
| --- | --- |
| `W A S D` | 移动 |
| `空格` | 冲刺（短暂无敌，可穿过敌人） |
| 自动 | 自动瞄准最近的敌人并射击 |
| `1 / 2 / 3` | 升级时选择强化 |
| `Esc` / `P` | 暂停 |
| `M` | 静音 |

## 三种模式

- **标准**：20 分钟完整长夜，难度循序渐进。
- **快速**：8 分钟浓缩夜晚，节奏更快。
- **噩梦**：20 分钟，敌人更硬、更痛，为老练者准备。

## 三种武器

进入任意模式后先选择起手武器，选择会被记住：

- **守夜人手枪**：均衡可靠，单发高伤，带 1 点穿透。
- **守夜人霰弹枪**：一次 5 颗弹丸，贴脸爆发极高，血量更厚。
- **连发手弩**：射速极快、弹道精准，适合走位与手感流。

## 内容

- 6 种普通敌人 + 4 场 Boss 战，每场 Boss 有不同的攻击方式；Boss 降临前有 3 秒预警。
- 26 种强化、5 档稀有度，每局随机三选一，可重掷；每次升级保证至少一张输出牌。
- 暴击、穿透、散射、燃烧、冰冻、连锁闪电、爆炸、环绕光球、荆棘光环、吸血、复活等 Build。
- 屏幕震动、命中停顿、慢动作、伤害数字、粒子、血迹、雾气、动态光照、黎明渐变。
- 低血量红晕与心跳反馈。
- 程序化 WebAudio 音效与环境氛围声。
- 设置面板：主音量、屏幕震动、伤害数字、减少动态效果、画质（自动 / 高 / 低）。
- 自动画质：帧率持续偏低时自动降档，恢复后自动升回。
- 守夜人档案：总场次、总击杀、通关次数、最佳存活，以及 6 项成就。
- 最高纪录、武器选择、设置、成就与最近 20 场战绩均保存在浏览器本地。

## 文件结构

```
index.html      页面、UI、样式（Cinzel 字体已内嵌）
js/art.js       所有怪物 / 地面 / 装饰 / 特效的程序化绘制
js/audio.js     WebAudio 音效与氛围声
js/upgrades.js  强化池与稀有度
js/game.js      游戏主循环、战斗、Boss、渲染、光照
serve.py        本地无缓存服务器（可选）
```
