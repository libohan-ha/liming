# Goal Document: 商业级改造 05 · 守夜人人物精修

## Go / No-Go
- **Judgment**: Go。
- **Reason**: 当前 main 已同步、无未提交修改；人物直接由 Canvas 绘制，具备独立重做条件，用户明确授权验证后提交推送。

## Target Outcome
回应 2026-10-22 用户“人物不精致”的反馈：以雨夜手绘猎人风格重做可读人物，完成六项真实变化：头脸与方向、分层服装材质、立体手脚与步态、三武器造型/握持、动态衣摆与动作、完整人物残影/受击反馈及缓存。正常缩放与手机画面可辨认，不靠加光圈遮盖形体。

## Goal Definition
- **Type**: product / quality / delivery。
- **Boundary**: 人物绘制资源、游戏绘制接入、离线测试、README 与验证证据。
- **Non-goals**: 新玩法、联网生图、怪物重做、碰撞与伤害调整。
- **Deferred work**: 多角色职业、付费皮肤。
- **Verification rule**: 新资源和行为先测试缺失，再实现；真实浏览器前后截图及完整流程回归。
- **Evidence source**: Node tests、语法检查、预览图像、DOM/console、Git。
- **Pass criteria**: 六项可见变化；正常游戏与手机角色更清晰；r=15、武器弹道/瞄准/触控不变；至少40秒推进无异常；公开提交仅代码/测试/说明，无临时截图或隐私。
- **Confidence note**: 测试不证明美术审美，必须看原尺寸截图；比较画面采用相同时间、相机与缩放，附放大细节仅作辅助。
- **Judgment owner**: 自动回归及本轮浏览器验收。

## Current State
- 人物帽沿覆盖脸，身体/靴子是基础椭圆；三武器外观相同；冲刺仅椭圆残影。
- art.js 已有超采样预渲染机制，但未缓存玩家；game.js 绘制玩家、护盾与灯光。
- 浏览器服务5178可启动；截图对窗口绘制可能延迟，需确认截图对应当前状态。

## Phases
### Phase 1: 基线和美术资源
- **Purpose**: 获得前后可比较的基线，建设精细部件。
- **Entry condition**: 目标已写，基线干净。
- **Phase rules**: 先RED；只改人物模块/资源，不动战斗。
- **Todos**:
  - [x] 捕获桌面及手机当前角色截图；Surface: 预览/本地对比图；Proof: 原尺寸图像；Depends on: 无。
  - [x] 构建头脸/衣料/靴子/三武器缓存；Surface: js/character.js、art.js；Proof: 资产测试与预览；Depends on: 基线。
- **Exit proof**: 资源测试通过，各部件能显示。
- **Stop condition**: 资源需联网或缓存无界增长。

### Phase 2: 动作和游戏接入
- **Purpose**: 正常游戏中精细且自然。
- **Entry condition**: 资产API可用。
- **Phase rules**: x/y/r/aim/武器伤害不变；动作只渲染变换，减少动态设置有效；护盾位置不变。
- **Todos**:
  - [x] 方向、步态、衣摆、握持和后坐接入；Surface: game.js/character.js；Proof: 方向截图、输入/武器回归；Depends on: 部件。
  - [x] 真实人物轮廓残影、受击覆盖、减弱动态与高对比；Surface: 渲染；Proof: 绘制预算/状态测试；Depends on: 接入。
- **Exit proof**: 六项变化在原尺寸可见，既有回归通过。
- **Stop condition**: 角色遮住大面积战场、动画改动影响碰撞。

### Phase 3: 验收和发布
- **Purpose**: 证明反馈落实并公开交付。
- **Entry condition**: 接入完成。
- **Phase rules**: console error先修；不提交临时图与私密文件；用户已授权main推送。
- **Todos**:
  - [x] 桌面/手机前后截图、40秒运行、菜单/移动射击/升级/Boss/暂停/结算；Surface: 预览；Proof: 图像及状态/日志；Depends on: 实现。
  - [x] 全部JS检查、tests回归、README明确反馈已落实、验证文档；Surface: tests/docs；Proof: 输出；Depends on: 验收。
  - [ ] git add -A、中文六项提交及指定署名，推送main；Surface: Git；Proof: commit/push/clean；Depends on: 安全审查。
- **Exit proof**: 推送成功且工作树干净。
- **Stop condition**: 无法完成预览、测试失败或公开内容包含敏感文件。
