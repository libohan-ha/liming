# 守夜人装备精修与动力学增强验证 · 2026-10-28

## 目标

持续落实 2026-10-22「人物贴图效果很一般、不精致」反馈，在 08 轮整身深色军装猎人骨架重绘的基础上，针对「随身配件细节」、「多角度帽子透视立体感」、「武器工艺材质」与「运动/体况动力学叙事」进行二次精雕细琢；坚持代码程序化生成与离屏缓存，不加无关玩法，不以堆光晕或纯换色掩盖造型，实现商业级精细度与工业级运行性能。

## 本轮 6 项实质性改进

1. **美术 / 随身配件**：新增独立高光圣化以太玻璃瓶（`vial`）与复古皮质弹药匣（`gear-pouch`），带蓝调半透明液面折射、黄铜领箍与搭扣细节，并挂载于腰间随身躯与呼吸自然晃动。
2. **美术 / 视角立体几何**：重构五向透视三角猎人帽（`head(c, view)`），背面、侧面、四分之三与正面拥有完全独立的冠部折痕、卷边羽翼剪影与飘带下垂层次，彻底消除各方向头部千篇一律的平面贴纸感。
3. **美术 / 武器材质与枪口工艺**：全面精修六种武器程序化纹理，加入发蓝冷钢顶面高光、胡桃木手柄防滑滚花、独立黄铜准星颗粒与进化版光流刻线，枪口火花增补向外飞溅的光芒辐射，暗场持枪金属质感显著提升。
4. **美术 / 提灯多层结构**：升级双层冲孔排气提灯（`lantern(c)`），增加黄铜导流顶盖与内嵌炽热灯芯，提灯骨架折面强化，地面保留独立暖色衰减光池，确保角色在完全黑暗的边缘仍有自然轮廓分离。
5. **动画与动力学 / 冲刺与低血量叙事**：冲刺时增加深层气动前倾俯冲（`dashLean: -0.26`、`crouch: 1.25`）与披风/围巾后摆空气阻力拖拽；引入残血濒危呼吸心肺动力学（`lowHp` 触发 3.8Hz 快速急促起伏），身体与体力状态更直观。
6. **性能与缓存契约**：全套新增配件与材质无缝融入 3× 超采样双离屏图集（彩色 + 遮罩孪生），部件数扩展至 36 个，严格约束显存占用 1.97 MiB（远低于 8 MiB 上限），运行时零渐变/零画布分配，单帧绘制耗时稳在 0.42 ms。
