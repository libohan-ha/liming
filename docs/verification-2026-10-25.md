# 守夜人三次精修验证 · 2026-10-25

## 目标

继续落实 2026-10-22「人物贴图一般、不精致」反馈。本轮以真实游戏中的人物可读性和精细度为第一优先，新增辨识度部件、关节结构、持枪姿态和行走/冲刺姿态；碰撞半径、弹道枪口、自动/定向瞄准、触屏与本地存档保持兼容。

## 本轮改动

1. **标志性轮廓**：新增破羽帽饰，作为守夜人不对称的远距离识别点，并跟随头部方向、呼吸与披风摆动。
2. **胸部识别件**：新增黄铜罗盘胸针，独立于躯干图层绘制，站立和移动时保持贴身。
3. **膝部结构**：新增独立膝甲与高光/暗边，接在左右腿步态上，避免腿部看起来像连续软管。
4. **脚部落地感**：新增独立鞋跟和鞋底纹理，跟随靴子步幅和冲刺下压，强化脚与地面的关系。
5. **呼吸与站姿**：静止时胸部、头部、围巾和提灯做低幅呼吸联动；移动时加入重心侧移与持枪支撑，人物不再是平面旋转。
6. **冲刺动作**：冲刺时降低身体、前倾并压低武器支撑，继续使用完整姿态残影；没有改变速度、无敌帧或碰撞逻辑。
