# 守夜人装备叙事与布料空气动力学验证 · 2026-10-29

## 目标

持续落实 2026-10-22「人物贴图效果很一般、不精致」反馈。09 轮补齐了帽子透视与武器工艺，本轮把人物从「穿得精致」推进到「带着一套干活的家伙事儿、动作有重量」：新增腰间工具串、袖口衬衫分层、弹链肩带、皮革枪套四个叙事部件，并把后坐力从手臂传导到脚底、给所有布料部件接入空气拖拽。不加无关玩法，不以光晕换色凑数；碰撞半径 15、枪口锚点 (24,0)、自动/定向瞄准、触屏与本地存档全部保持兼容。

## 本轮 6 项实质性改进

1. **美术 / 腰间工具串**（新部件 `belt-tools`）：猎人短刀（鹿角柄 + 单亮刃 + 黄铜护格）、双圈绳钩与皮扎地图卷，一组挂在左腰的「干活装备」，随髋部摆动并滞后躯干，1× 缩放下读作一个带亮边的深色质量块。
2. **美术 / 袖口衬衫分层**（新部件 `cuff-shirt` / `support-cuff`）：外套袖口与手套之间补一层亚麻衬衫卷边 + 皮革腕带，持枪手与双手武器的支撑手都有「袖→衫→腕→套」四层关节，手腕不再直接断在枪上。
3. **美术 / 弹链肩带**（新部件 `bandolier`）：斜挎胸前的五连黄铜弹壳链，正面与四分之三视角的强身份标志；背面与后四分之三视角自动隐藏，不会在背部肩袢上穿帮。
4. **美术 / 皮革枪套**（新部件 `holster`）：右臀带固定皮袢的枪套，补全「守夜人枪手」剪影的最后一块，行走与冲刺时随髋部联动。
5. **动画 / 后坐重心传导**：开火后坐不再只是手臂抖动——髋部后坐、靴跟压地（recoil 按 0.22/0.3/0.42 权重传导到腿、靴、靴跟），力量从脚底反推上来，霰弹枪大后坐时全身参与感显著增强。
6. **动画 / 布料空气动力学**：披风、围巾尾、提灯、帽羽接入统一的空气拖拽模型——静止时随呼吸二次摆动（滞后躯干 0.9 弧度），移动时沿速度反向后拖，冲刺时全部后扬；布料读作布料而不是纸板。期间发现帽羽/围巾后扬角过大会穿模帽冠，已收敛到安全幅度并补测试锁定。
