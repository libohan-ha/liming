# 守夜人整身重绘验证 · 2026-10-27

## 目标

2026-10-22 的反馈是「人物贴图效果很一般、不精致」。05～07 轮在旧画法上不断加部件，但人物仍然是「浅灰一团 + 宽檐帽 + 光晕盖在身上」，问题在造型本身，不在细节数量。本轮换掉画法，重画玩家整身：先定风格（深色军装猎人、暖提灯、冷月边光、三段明度），再重做轮廓、比例、头脸体积、腿脚结构与行走动画；不加玩法，不靠换色或堆粒子掩盖造型。

## 本轮改动

1. **整身轮廓与比例重画**：躯干从宽椭圆改成有肩、腰、胯的真实人体剪影，头部按 0.88 缩放并以颈部为轴，下摆收短、双腿改画在裙摆之前。远看是「一个人」，不再是插着帽子的浅色团块。
2. **头脸分层**：帽檐压出一道暗带，额、颧、下颌各自成面；鼻子拆成鼻梁、鼻头、鼻翼三个受光块；眼睛先画眼窝再叠眼白、虹膜、瞳孔与高光，嘴用上唇暗面、下唇亮面、人中与下巴受光收口，脸缘留一道冷月边光。正常缩放下能看出这是一张脸。
3. **深色分层配色**：外套由浅灰改为深海军蓝三档明度，只保留提灯的暖色反弹面和背光侧的纯暗面；钢材压暗、只留一条亮顶边。人物在暗场里靠明度分层立起来，而不是靠加法光晕发白。
4. **腿脚结构**：裤腿分出膝弯，膝盖独立抬起、脚掌随步幅滚动；衣摆左右两片各自摆动，双腿从裙摆前面走出来，不再是一条连着的模糊裙筒。
5. **行走与转身动画**：新增重心侧移、上身反向扭转、手臂反摆、左右膝相位与脚掌滚动六组姿态量，全部接入减少动态开关（开启时归零）；转弯时头部带动帽饰轻微滞后，朝向更好读。
6. **光照层次与残影质量**：提灯光晕从「压在人物上面」改成先画在人物身后，光是落在地上的；脚下另加一层冷光池与随身位下沉的接触阴影，冲刺时阴影下压变淡；冲刺残影改为按 7 像素间距取样、最多 7 张，画面更干净、人物绘制量减半。

## 浏览器验证

本地 5178 服务器 + 真实 classic scripts + Canvas，桌面画布 1066×600（DPR 1）：

- 菜单 → 开始游戏：`state=playing`。
- 移动 + 自动射击：按住 W/D 推进 3 秒，位置从原点移动到 `(501, -501)`，弹道在飞，`state=playing`。
- 升级三选一：`window.__game.levelUp()` → `state=levelup`，三个候选 `chain,dashdmg,pierce`，按 `Digit1` 后回到 `playing`。
- Boss：`window.__game.spawnBoss()` 后推进 2 秒，`g.boss` 存在，`state=playing`。
- 暂停：`Esc` → `state=paused`；再按 `Esc` → `playing`。
- 30 秒以上连续运行：`step(1/60, 1900)`（约 31.7 秒）无异常抛出，画面继续渲染；另跑 `step(1/60, 900)` 走到结算流程。
- 结算：致命伤后进入 `state=ending`，播完后 `state=over`，`#end-screen` 显示；随后重新开局进入 `playing`，无报错。
- 控制台：整轮走查 **零 console 输出**（无 error / warn）。
- 手机 375×812：`zoom=1.00`，画布 468×1015，`scrollWidth=375` 无横向溢出，触屏摇杆与「冲刺」按钮正常，推进 10 秒击杀 5 个，无报错。

## 性能数据

- 人物图集：2 张画布，768×336，3× 超采样，合计 1.97 MiB（上限 8 MiB）。
- 缓存部件 34 个，初始化后逐帧不新建画布、不建渐变。
- 单帧人物绘制：普通画质 48 次 `drawImage`，低画质 24 次；单次绘制实测 **0.305 ms**。
