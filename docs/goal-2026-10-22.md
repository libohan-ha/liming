# Goal Document: 商业级改造 04 · 风雨中的守夜人

## Go / No-Go
- **Judgment**: Go。
- **Reason**: 现有单机 Canvas 游戏和预览调试接口可用，无需引入运行时网络依赖；用户已授权本轮提交及推送。

## Target Outcome
交付六项可体验的改进：鼠标定向瞄准、守夜灯塔据点、精准闪避奖励、暂停构筑与进化路线、武器差异音效与场景混音、程序化雨夜氛围。保留自动射击、触屏操作和原有存档，完成全流程试玩后推送 main。

## Goal Definition
- **Type**: product / quality / delivery。
- **Boundary**: 游戏 HTML、JS、离线测试和说明；不联网、不新增外部素材。
- **Non-goals**: 联机、账号、付费系统、引擎重写。
- **Deferred work**: 多场景战役、云存档和第三方素材。
- **Verification rule**: 新功能测试先失败再通过，浏览器逐项交互，旧流程完整回归。
- **Evidence source**: Node 测试、语法检查、预览状态/截图/日志、Git 输出。
- **Pass criteria**: 六项功能可观察；菜单/开局/移动射击/升级/Boss/暂停/结算无报错；推进至少 40 秒无异常；公开仓库只提交游戏及测试文档。
- **Confidence note**: 手动推进验证逻辑，实时预览验证渲染与输入；不把模拟性能当作用户设备帧率。
- **Judgment owner**: 自动测试及本轮浏览器验收。

## Current State
- 四种模式、三种武器及进化、功能掉落、雷达、设置、永久天赋已有。
- 自动瞄准，战场暂无可争夺的中立目标；暂停仅有基础统计。
- 音效程序生成，音频与渲染功能需要防止高密度声音/粒子叠加。
- 当前 main 与 origin/main 一致，工作树干净。

## Priority Rationale
先明确可测玩法边界，再接入表现层；新增功能采用独立离线模块，减少对成熟战斗代码的侵入。最后一次性回归原有流程并审查待提交文件。

|---|---|---|---|

## Phases
### Phase 1: 可测玩法切片
- **Purpose**: 交付可控瞄准、地图目标和技巧反馈。
- **Entry condition**: 目标文档已写，仓库基线明确。
- **Phase rules**: 先写缺失行为测试；不改现有升级倍率/存档键；新增状态不依赖网络。
- **Todos**:
  - [x] 定向瞄准、灯塔充能、精准闪避：JS 模块及游戏钩子；证明为离线测试与预览行为；无前置依赖。
  - [x] 暂停构筑：HTML/JS/CSS；证明为暂停展示持有升级及当前进化条件；依赖现有升级定义。
- **Exit proof**: 核心逻辑测试通过，浏览器可触发四项行为。
- **Stop condition**: 旧输入或结算状态损坏，先修复不继续堆功能。

### Phase 2: 程序化表现与反馈
- **Purpose**: 雨夜空间层次、可辨认音效和暂停静音场景。
- **Entry condition**: 模块接口及预算明确。
- **Phase rules**: 美术与音频限定独立文件；低画质/减少动态效果要降级；不加入素材下载。
- **Todos**:
  - [x] 武器差异音色、脚步、灯塔与闪避音效、暂停混音：audio.js；证明为离线合成测试及预览日志；依赖玩法事件。
  - [x] 雨丝、水洼涟漪与灯塔图形：程序化绘制模块；证明为对象预算测试及截图；依赖游戏渲染钩子。
- **Exit proof**: 音频自动测试无非法时间参数；天气遵守预算，减少动态模式无雨丝运动。
- **Stop condition**: 音频节点无界增长或画面妨碍敌人识别。

### Phase 3: 回归与发布
- **Purpose**: 本轮可复现、可追踪地交付。
- **Entry condition**: 六项实现完成。
- **Phase rules**: 不提交密钥、个人信息、临时 QA 图片；测试失败不能报告完成。
- **Todos**:
  - [x] 四份 JS 逐个 node --check，新模块及 tests 同时检查；证明为命令输出。
  - [x] 菜单、移动/射击、升级、Boss、暂停、胜负结算、40 秒运行和手机布局；证明为预览状态与日志。
  - [ ] 更新 README/测试证据，审查 diff，提交中文六项概括及指定署名，推送 main；证明为 commit/hash 和 push 输出。
- **Exit proof**: GitHub main 推送成功，工作树干净。
- **Stop condition**: 推送失败、公开内容含敏感信息或尚有 console error。

## Dry-Run Findings
- 现有粒子更新在正常循环中重复调用，新增天气独立维护，避免借用现有粒子寿命。
- 暂停期间音频仍播放，需要明确 pause 状态钩子，恢复时不可重新叠加环境节点。
- 鼠标坐标必须使用实际画布矩形、相机和 zoom，手机继续自动瞄准。
- 灯塔奖励直接累积经验并走原升级队列，不能在绘制时发奖。

## Final Validation
Node 核心/音效/绘制测试；四份指定 JS 及新模块语法检查；浏览器全流程与 40 秒推进；低画质/减少动态降级；公开提交审查；main push。

## First Execution Step
在隔离的功能分支创建离线行为测试，确认新玩法函数缺失导致 RED，再实现对应模块并接入游戏。
